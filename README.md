# Учебный пример Holkas

Этот репозиторий показывает результат сохранения объекта базы в Git через
[Holkas](https://holkas.belousov.net.ru/) — инструмент переноса доработок КОР Парус 8.

В каталоге `FunctionPostgres/` находится учебная функция
`parus.f_hksite_contract_check`, сериализованная Holkas в YAML.

В истории показаны две версии правила:

- **1.1:** сумма договора должна быть больше нуля;
- **1.2:** сумма договора должна быть не меньше 100.

Оба сохранения выполняет Holkas: читает функцию из учебной базы PostgreSQL,
сравнивает её с репозиторием и записывает изменение коммитом. Откройте историю
файла и diff второго сохранения, чтобы увидеть результат.

Это специально созданный учебный объект. Исходников Holkas, рабочих данных,
параметров подключения и секретов в репозитории нет. Функция иллюстрирует перенос
и не является готовым решением согласования договоров в Парусе.
